模型被換掉,或算歪了

站③ 模型:大腦被動過手腳,你卻看不出來

▶ 看影片 🎓 資安攻防 🎬 12 個段落 🀄 投影片 + 逐字稿
本集開場

這一集我們走到第三站——模型。前兩站講的是餵給 agent 的東西被下毒;這一站更狠,是 agent 的『大腦』本身被換掉,或者為了省錢,被換成一顆算歪的腦。而最麻煩的地方是:它算歪的那個當下,吐出來的東西看起來還是一切正常,你根本察覺不到。

1

站③ 是什麼:大腦被動手腳

  • 1模型 = agent 的判斷核心,一切決策靠它
  • 2它被換成動過手腳的版本,或被降級
  • 3護欄一旦被吃掉,整條流程跟著算歪
逐字稿

先定義這一站。模型,就是 agent 的大腦——它讀完所有資料、做出所有判斷,該不該放行、該不該執行,全看它。所以只要這顆腦被換成動過手腳的版本,或者被換成一顆偷工減料的降級版,它裡面的安全護欄被吃掉,那後面每一步判斷,都會跟著一起算歪。

2

先看正常怎麼用

逐字稿

老規矩,先看懂正常。假設你交辦一個要判斷的任務:審核這筆退款該不該過。agent 讀完訂單資料,交給模型判斷。這顆模型來源是固定的、版本是鎖死的、檔案雜湊也驗過,所以它護欄完整,遇到越權的退款就照規則擋下來。這就是一顆可信的大腦,該擋的它會擋。

3

正常裡夾的那個小錯

  • 1為省算力、省成本,換一顆降級模型
  • 2或隨手抓一顆來源不明的版本來用
  • 3當下跑得動、看起來對,你不會起疑
逐字稿

但正常使用裡,一樣會夾一個小錯。最常見的兩種:一種是為了省算力、省成本,把原本那顆換成壓縮過、降級過的便宜版本;另一種是隨手從外面抓一顆來源不明的模型就上。共通點是——換上去當下,它跑得動、答得出來、看起來都對,所以你根本不會起疑。

4

錯誤點與結果,隔很遠

逐字稿

這張最要命。你降級或換模型的那個當下,錯誤點,是沒有感覺的——輸出看起來全對,沒人反推得出這顆腦被動過手腳。等到某天它把該擋的越權操作放行了,結果才爆。資安團隊回頭查,模型是個黑盒,他們從結果反推不出根因;更慘的是這顆腦早就在線上,牽動整條流程,要換得花大錢急換,甚至整段停機。

5

它到底怎麼被攻的:兩條路

  • 1偷換:塞一顆植入後門的版本給你
  • 2植入:被 fine-tune 埋進特定觸發行為
  • 3降級:壓縮 / 蒸餾把對齊護欄一起削掉
逐字稿

拆開講它怎麼被攻。第一條是偷換:攻擊者在供應鏈某一環,把你要載的模型換成一顆植入後門的。第二條是植入:模型被人拿去 fine-tune,埋進一個特定觸發字就聽話的隱藏行為。第三條是降級:你自己為了省錢做壓縮、蒸餾,結果連帶把對齊、把安全護欄也一起削掉了。

6

毒怎麼從大腦上車

逐字稿

看這條攻擊鏈。同樣五個角色,唯一的差別在模型這一格:大腦被換成植後門、或降級的版本。工具照樣讀資料、agent 照樣送 context,但模型的護欄已經被吃掉,判斷已經算歪。它回一個看起來正常、其實放行了越權退款的答案,執行層照著跑,錢就真的匯出去了。整條路上,表面上一切正常。

7

為什麼傳統防護擋不住

  • 1模型是黑盒,輸出看起來正常
  • 2防火牆 / 防毒看流量,看不進判斷
  • 3很難從結果反推『它被換過、算歪了』
逐字稿

那為什麼你現有的防火牆、防毒擋不住?因為它們看的是流量、是檔案特徵,看不進模型內部的判斷。而模型本身是個黑盒,你丟進去、它吐出來,吐出來的東西看起來完全正常。你幾乎不可能光看一個結果,就反推出這顆腦被換過、或是算歪了。沒有異常訊號,傳統那套自然抓不到。

8

怎麼防①:出處固定 + 鎖版本

  • 1模型來源固定,只從可信管道拿
  • 2下載後驗雜湊,對得上才准用
  • 3鎖版本:不放任它自動換、自動升
逐字稿

開始設閘。第一道:管住這顆腦的來源。模型只從可信的管道拿,不隨手抓路邊的;拿到之後一定驗雜湊,對得上你記錄的那一份,才准裝上去。然後鎖版本——不要放任系統自動換模型、自動升級,每一次換腦都要是你知情、你點頭的。來源固定加驗證加鎖版本,先把偷換這條路堵掉。

9

怎麼防②:關鍵輸出要驗

  • 1對高風險判斷做獨立驗證,不只信一句話
  • 2上線前紅隊測試:拿已知攻擊去打它
  • 3行為對不上基準,就當它已經被動過
逐字稿

第二道:別百分之百信這顆腦的一句話。凡是高風險的判斷——放行金流、刪資料、給權限——都對它的輸出再做一次獨立驗證,規則對不上就攔下來。上線前也要紅隊測試,拿一批已知的攻擊、已知的越權情境去打它,看它會不會破。只要它的行為跟你的基準對不上,就先當它已經被動過手腳。

10

怎麼防③:別為省錢無腦降級

  • 1降級前先問:這一步的護欄能不能省
  • 2省算力,不能省掉安全那一塊判斷
  • 3壓縮 / 蒸餾後,一定重跑安全測試
逐字稿

第三道,也是最容易犯的:別為了省錢就無腦降級。要換便宜、換小模型之前,先問一句——這一步的護欄,是不是被你一起省掉了?省算力可以,但安全那一塊判斷不能省。如果真的做了壓縮、蒸餾,換完一定要把安全測試重跑一遍,確認護欄還在,而不是省錢省到把煞車也拆了。

11

這一站跟前兩站不一樣

  • 1站①站②:被動手腳的是『餵進去的東西』
  • 2站③:被動手腳的是『判斷的那顆腦』
  • 3所以驗輸入不夠,還要驗『腦』本身
逐字稿

補一個關鍵區別。站一、站二,壞掉的是餵給模型的東西——工具的資料、上下文的指令;你把輸入洗乾淨,問題就緩解一大半。但站三不一樣,壞掉的是做判斷的那顆腦本身。所以光把輸入驗乾淨不夠,你還得回頭驗這顆腦——它是不是原廠的、有沒有被降級。輸入跟大腦,是兩個要分開守的東西。

12

帶走一句話

  • 1模型是黑盒:算歪了,輸出還是像對的
  • 2守出處、鎖版本、驗關鍵輸出
  • 3省算力可以,別省掉安全那一塊
逐字稿

這一集帶走一句話:模型是個黑盒,它算歪的時候,輸出看起來還是像對的——你不能等結果爆了才發現大腦被換過。所以守住它的出處、鎖死版本、對關鍵輸出再驗一次,並且記住:省算力可以,別把安全那一塊一起省掉。下一站,我們看模型吐出來的壞輸出。
